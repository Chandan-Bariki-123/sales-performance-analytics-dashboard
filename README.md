# Sales Performance Analytics Dashboard

## 📊 Project Overview

This project is an interactive Sales Performance Analytics Dashboard developed using Microsoft Excel.

The dashboard analyzes sales performance of sales executives across different regions and compares actual sales with assigned targets.

## 🛠️ Tools Used

* Microsoft Excel
* Excel Formulas
* Pivot Tables
* Pivot Charts
* Data Analysis
* Dashboard Development

## 📁 Dataset

The dataset contains sales performance information for different sales executives and regions.

Key fields include:

* Employee Code
* Sales Executive
* Region
* Daily Sales
* Total Sales
* Sales Target
* Target Hit %
* Away From Target %

## 🔧 Data Analysis

The data was analyzed to understand sales performance and target achievement.

The analysis includes:

* Total sales generated by each sales executive
* Comparison of sales with assigned targets
* Target achievement percentage
* Regional sales performance
* Identification of high-performing sales executives
* Identification of sales executives below their targets

## 📈 Dashboard Features

The Excel dashboard provides a visual overview of sales performance using charts and summary metrics.

It helps analyze:

* Sales Executive Performance
* Regional Performance
* Total Sales
* Sales Target
* Target Achievement
* Performance Comparison

## 💡 Key Business Questions

This dashboard helps answer questions such as:

1. Which sales executives generated the highest sales?
2. Which sales executives achieved their sales targets?
3. Which regions are performing better?
4. How much sales was generated compared with the assigned target?
5. Which sales executives are below their targets?

## 🎯 Project Objective

The main objective of this project is to demonstrate practical skills in Microsoft Excel, data analysis, dashboard creation and business performance reporting.
